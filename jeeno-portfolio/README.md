# Supalerk Chaonchom — Portfolio Website

เว็บพอร์ตโฟลิโอส่วนตัว สร้างด้วย HTML/CSS/JavaScript ล้วน (ไม่มี framework, ไม่ต้อง build, ไม่ต้อง `npm install`) ดังนั้นสามารถอัปโหลดขึ้น Vercel ได้ทันที

## โครงสร้างไฟล์

```
jeeno-portfolio/
├── index.html          # หน้าเว็บหลัก (ทุก section อยู่ในไฟล์เดียว)
├── css/style.css        # สไตล์ทั้งหมด
├── js/main.js            # การสลับภาษา TH/EN, scroll animation, accordion, mobile menu
└── assets/
    ├── avatar.jpg                    # รูปโปรไฟล์
    └── Supalerk_Chaonchom_CV.pdf     # ไฟล์เรซูเม่ (ปุ่ม Download CV จะโหลดไฟล์นี้)
```

## วิธี deploy ขึ้น Vercel ฟรี (ประมาณ 5 นาที)

มี 2 วิธี เลือกวิธีไหนก็ได้:

### วิธีที่ 1: ลากไฟล์วางตรงๆ (เร็วที่สุด ไม่ต้องรู้จัก Git)

1. ไปที่ https://vercel.com แล้วสมัคร/ล็อกอิน (สมัครฟรีด้วยอีเมลหรือ GitHub ก็ได้)
2. กด **Add New... → Project**
3. เลือกแท็บ **Deploy without Git** (หรือหน้าจะมีช่องให้ลากโฟลเดอร์วาง)
4. ลากโฟลเดอร์ `jeeno-portfolio` ทั้งโฟลเดอร์วางลงไป
5. กด **Deploy** รอประมาณ 30 วินาที เสร็จแล้วจะได้ลิงก์ฟรีทันที เช่น `jeeno-portfolio.vercel.app`

> ข้อเสียของวิธีนี้คือถ้าจะแก้ไขเนื้อหาทีหลัง ต้องลากโฟลเดอร์ใหม่ทุกครั้ง — ถ้าคิดว่าจะแก้บ่อย แนะนำวิธีที่ 2

### วิธีที่ 2: ผ่าน GitHub (แก้ไขทีหลังง่ายกว่า, อัปเดตอัตโนมัติทุกครั้งที่ push)

1. สร้างบัญชี GitHub ฟรีที่ https://github.com (ถ้ายังไม่มี)
2. สร้าง repository ใหม่ (New repository) ตั้งชื่อเช่น `jeeno-portfolio` — เลือก Public หรือ Private ก็ได้
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repository (ใช้ปุ่ม "uploading an existing file" บนหน้าเว็บ GitHub ได้เลย ไม่ต้องใช้คำสั่ง Git ก็ได้)
4. ไปที่ https://vercel.com → **Add New... → Project**
5. เลือก **Import Git Repository** แล้วเชื่อมบัญชี GitHub ของคุณ เลือก repo `jeeno-portfolio`
6. Vercel จะตรวจพบว่าเป็น static site อัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม กด **Deploy**
7. เสร็จแล้วจะได้ลิงก์ เช่น `jeeno-portfolio.vercel.app`
8. ครั้งต่อไปถ้าอยากแก้เนื้อหา แค่แก้ไฟล์ใน GitHub แล้ว Vercel จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ

## ผูกโดเมนของตัวเอง (ถ้ามี หรืออยากซื้อ)

1. ในหน้าโปรเจกต์บน Vercel ไปที่แท็บ **Settings → Domains**
2. พิมพ์ชื่อโดเมนที่ต้องการ (เช่น `jeenodesign.com`) แล้วกด **Add**
3. ถ้าโดเมนซื้อจากที่อื่น (GoDaddy, Namecheap ฯลฯ) Vercel จะให้ค่า DNS records มาให้ไปตั้งค่าในระบบที่ซื้อโดเมน
4. ถ้ายังไม่มีโดเมน สามารถซื้อผ่าน Vercel ได้เลยในหน้าเดียวกัน (มีค่าใช้จ่ายรายปีตามชื่อโดเมน แต่ตัว hosting ยังฟรี)

## แก้ไขเนื้อหาเอง

- ข้อความทุกจุดที่มีทั้งภาษาไทย/อังกฤษ จะอยู่ใน `index.html` ในรูปแบบ `data-en="..."` และ `data-th="..."` — แก้ตรงนี้ได้เลยทั้งสองภาษา
- ลิงก์ผลงาน (Work section) ชี้ไปที่ Artifact บน claude.ai ของแต่ละ case study — **ก่อน publish ควรตรวจสอบว่า artifact นั้นแชร์แบบเปิดให้คนอื่นดูได้แล้ว** (ไม่ใช่ private เฉพาะบัญชีตัวเอง) ไม่งั้นคนที่กดลิงก์จากพอร์ตจะเข้าดูไม่ได้
- รูปโปรไฟล์และเรซูเม่ อยู่ในโฟลเดอร์ `assets/` เปลี่ยนไฟล์ได้โดยตรง (ใช้ชื่อไฟล์เดิม หรือเปลี่ยนชื่อในไฟล์ `index.html` ให้ตรงกัน)
